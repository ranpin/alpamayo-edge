Alpamayo-R1 轨迹预测 · 真实帧叠加

NVIDIA Alpamayo-R1（10B 自动驾驶 VLA）部署在 Jetson AGX Orin（TensorRT-Edge-LLM 三引擎），对真实驾驶片段输出 6.4 秒未来轨迹，与真值（GT）一起用该片段的鱼眼相机标定投影叠回原始前视相机画面。全部为 Orin 实机推理输出。

演示

每张图为一个真实驾驶片段的前视相机原始帧，叠加两条 6.4 秒未来轨迹：GT 真值（绿）取自数据集 egomotion 标签、Alpamayo-R1 预测（蓝）为 Orin 实机推理输出。两者都用该片段实测的鱼眼标定投影回图像平面，因此贴合实际路面。

卡片标签 「6.4s 终点：前行 X m · 左/右偏 Y m」 是该片段 GT 轨迹在 6.4 秒预测窗末端、相对自车 t₀ 位置的位移分解——前行 X m 为纵向分量、左/右偏 Y m 为横向分量，合起来描述终点落在哪（一个位移矢量的两个分量），不是「先直行 X m 再转弯」这类分段机动指令。卡片另标初速 v₀ 与 ADE@6.4s（误差指标的公式与口径见下方「评测结果」），以及模型同时产出的思维链（CoT）。每张图右上角的序号 1–6 按 ADE@6.4s 从好到差编排，与下方「评测结果」表逐行对应。

评测结果

测试数据集：NVIDIA PhysicalAI-AV 数据集 dgural 公开 sample 的 6 个 clip——前视广角相机真实帧 + ~100Hz egomotion GT 轨迹；6 个片段均为「6.4s 预测窗内明显转弯」的困难样本（非随机抽样，见下方「口径与诚实边界」）。推理口径：Alpamayo-R1（TRTEdge FP16）Jetson Orin 实机、单噪声种子（seed=5、temperature=0）确定性推理，无训练微调。

下表为 6 个片段上 R1 预测相对 GT 的逐点欧氏位移误差（ego 系，按 ADE@6.4s 升序）。核心观察：R1 的思维链与其轨迹精度强相关——当 CoT 正确识别出机动（如「绿灯左转」「并入右转道」）时轨迹几乎完美贴合（ADE 低至 0.84m）；当 CoT 退化为泛化的「跟前车」时，模型会漏判或欠判即将到来的转弯（最差例蓝线直冲、绿线左拐，ADE 5.90m）。

误差公式：ADE@T（平均位移误差）= 预测与 GT 在前 T 秒每个 waypoint 上欧氏距离的均值 = (1/N)·Σᵢ‖predᵢ − gtᵢ‖；FDE@T（终点位移误差）= 第 T 秒末 waypoint 的欧氏距离 = ‖pred_N − gt_N‖。@3s 取前 30 点、@6.4s 取全部 64 点（10 Hz）；均在 t₀ 时刻 ego 系（自车为原点、x 前 y 左）计算，单位米。
口径与诚实边界：① 单噪声种子（seed=5、temperature=0）确定性推理，非官方 minADE6（6 采样取最优）；② 6 个片段均为「6.4s 预测窗内明显转弯」的困难样本、非随机抽样，误差天然高于官方全集；③ 数据源 dgural 公开样本的 README 明确声明「不适合 benchmarking / 统计分析」——本页数字仅为逐例行为展示，不构成代表性精度结论；④ 官方 Alpamayo-R1 在 644 clip 上报告 minADE6@6.4s≈0.79m，口径不同，不可与本表直接比较。

核心方法

  • 模型：Alpamayo-R1 = VLM backbone（Qwen3-VL 8B）+ 扩散动作专家（2.3B），单次推理同时产出思维链文本与动作头输出。
  • 输入：4 路相机（cross_left / front_wide / cross_right / front_tele）× 4 个历史时刻（t₀−0.3…t₀）共 16 帧 + 16 点 ego 历史轨迹。
  • 输出：思维链（CoT）文本 + output_trajectory [64,2]（归一化 accel, κ）；动作头输出积分后得 BEV 轨迹（见下「轨迹积分」）。
  • 边缘部署：TensorRT-Edge-LLM 三引擎（llm / visual / action）建于 Jetson AGX Orin（sm_87 / JetPack 6.2）。action 专家的 Attention/RotaryEmbedding/TensorScatter 算子需 TRT≥11，用分解注意力补丁打穿该墙（Orin 的 TRT 10.7 不原生支持）。
  • 轨迹积分：动作头输出经运动学自行车模型积分得 BEV 轨迹（6.4s / 64 点 / 10Hz）；初速 v₀ 由 ego 历史经官方 compute_minade 的最小二乘（Cholesky）反解，与 minADE 评测同一套后处理口径。
  • 投影叠加：GT 与 R1 轨迹均用该片段实测的鱼眼相机标定（多项式畸变 fw_poly + 四元数外参）投影回前视图像；GT 带真实路面高程 z，R1 的 2D 输出按 GT 路面高程插值赋 z，使两者都贴合路面。
  • 数据来源：图像帧取自 dgural 公开样本（NVIDIA PhysicalAI-AV 的公开 100-clip 子集）；GT 轨迹与相机标定取自 gated NVIDIA PhysicalAI-AV；帧↔egomotion 时间对齐用数据集自带的逐帧时间戳权威校准（非按 fps 推算）。
